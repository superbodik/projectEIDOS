## 🔴 КРИТИЧЕСКИЕ БАГИ (Crash / Data Corruption)

### ✅ БАГ-001: `StatsType()` возвращает неверную строку для `StatType::Social`
- **Файл:** `src/Logic/EidosTypes.h`
- **Проблема:** В switch-case для `StatType::Social` возвращается `"Endurance"` вместо `"Social"` (copy-paste ошибка).
- **Исправлено:** `case StatType::Social: return "Social";`

### ✅ БАГ-002: Координаты текстур для `AcaciaLog` и `JungleLog` перепутаны
- **Файл:** `src/World/Chunk.cpp`, функция `GetTextureUV()`
- **Проблема:** Для `AcaciaLog` и `JungleLog` стороны были перепутаны (акация получала текстуру джунглей и наоборот), а верх/низ использовали дубовый top.
- **Исправлено:** `AcaciaLog → col=5, row=6; JungleLog → col=6, row=6` (пока без отдельных top-текстур, будет добавлено в v0.6.1)

### ✅ БАГ-003: Двойной `#pragma once` в `EidosTypes.h`
- **Файл:** `src/Logic/EidosTypes.h`
- **Исправлено:** Удалён дубликат.

## 🟠 ВЫСОКИЕ БАГИ (Логика / Геймплей)

### ✅ БАГ-004: `GetBiomeFromString` — отсутствуют маппинги для многих биомов
- **Файл:** `src/World/WorldGenerator.cpp`
- **Исправлено:** Добавлены все 15 маппингов: Ocean, Beach, Scorched, Desert, Savanna, Jungle, TemperateDesert/Dry Plains, Forest, Rainforest, Taiga, Tundra, SnowyTundra, IceSpikes, Mountains, River. Добавлена поддержка lowercase-вариантов.

### ✅ БАГ-005: `UpdateCameraPro` — конфликт режимов камеры
- **Файл:** `src/Entities/Player.cpp`
- **Исправлено:** Установлен `camera.mode = CAMERA_FIRST_PERSON`, убран `GetMouseDelta` из вызова `UpdateCameraPro`. Raylib сам управляет мышью в этом режиме.

### ✅ БАГ-006: `ResolveSurface` / `ResolveSubsurface` — мёртвый код
- **Проблема:** В конце функций есть `(void)x; (void)surfaceY;` — эти строки никогда не выполняются, так как все пути выше завершаются `return`. Параметры `x` и `surfaceY` заявлены, но не используются.
- **Исправление:** Либо удалить неиспользуемые параметры из сигнатуры, либо пересмотреть логику.

### БАГ-007: `Player::UpdateSurvival` — проверка коллизии головы на 1.0 вместо `playerHeight`
- **Файл:** `src/Entities/Player.cpp`, функция `UpdateSurvival()`
- **Проблема:** `blockInHead` проверяется на высоте `position.y + 1.0f`, но `playerHeight = 1.8f`. Блок на высоте 1.5 останется незамеченным.
- **Код:** `BlockType blockInHead = getBlock((int)floor(position.x), (int)floor(position.y + 1.0f), (int)floor(position.z));`
- **Исправление:** `position.y + playerHeight - 0.01f`

### БАГ-008: `ExecuteCommand` — небезопасный вызов `::isdigit`
- **Файл:** `src/Core/Debug/GameConsole.cpp`, функция `ExecuteCommand()`
- **Проблема:** `::isdigit(c)` с типом `char` вызывает undefined behaviour для отрицательных значений (символы вне ASCII). Нужно привести к `unsigned char`.
- **Исправление:** `::isdigit(static_cast<unsigned char>(c))`

### БАГ-009: `Cmd_Give` — та же проблема с `::tolower`
- **Файл:** `src/Core/CommandManager.cpp`, функция `Cmd_Give()`
- **Проблема:** `std::transform(name.begin(), name.end(), name.begin(), ::tolower)` — UB для отрицательных char.
- **Исправление:** Использовать лямбду с `static_cast<unsigned char>`.

## 🟡 СРЕДНИЕ БАГИ (Производительность / Надёжность)

### БАГ-010: `autoSaveTimer` не сбрасывается при загрузке мира
- **Файл:** `src/Core/EidosEngine.cpp`, функция `LoadWorld()`
- **Проблема:** После загрузки мира таймер автосохранения сохраняет предыдущее значение. Если таймер был > 60с, автосохранение сработает сразу после входа в мир.
- **Исправление:** `autoSaveTimer = 0.0f;` в конце `LoadWorld()`.

### БАГ-011: `SetBlockGlobal` позволяет ставить блок внутри игрока
- **Файл:** `src/Core/EidosEngine.cpp`, функция `SetBlockGlobal()`
- **Проблема:** При размещении блока не проверяется коллизия с игроком. Можно запереть себя в блоке.
- **Исправление:** Добавить проверку пересечения с AABB игрока.

### ✅ БАГ-012: `CalculateBasicSunlight` не обновляет свет в соседних чанках
- **Файл:** `src/World/Chunk.cpp`, функция `CalculateBasicSunlight()`
- **Проблема:** При расчёте освещения учитывается свет только внутри текущего чанка. После установки/удаления блока на границе, соседний чанк не пересчитывает свой свет до следующей перестройки меша.
- **Исправлено:** `SetBlockGlobal` помечает соседние чанки как `dirty = true` при изменении блоков на границе (x%16==0, x%16==15, z%16==0, z%16==15).

### ✅ БАГ-013: Солнце и Луна движутся только в плоскости X-Y
- **Файл:** `src/World/SkySystem.cpp`, функция `CalculateCelestialPositions()`
- **Проблема:** `sunPosition.z = centerPos.z;` и `moonPosition.z = centerPos.z;` — Z координата всегда фиксирована. Небесные тела не описывают эллиптические орбиты.
- **Исправление:** Добавить Z-компоненту: `sunPosition.z = centerPos.z + sinf(angle) * dist * 0.3f;`

### ✅ БАГ-014: `IsChunkInFrustum` — фрустум-куллинг не реализован
- **Файл:** `src/Core/EidosEngine.cpp`, функция `IsChunkInFrustum()`
- **Проблема:** Функция всегда возвращает `true`. Все чанки всегда отрисовываются, даже те, что за камерой.
- **Код:** `bool EidosEngine::IsChunkInFrustum(Chunk* chunk) const { (void)chunk; return true; }`
- **Исправлено:** Реализована проверка пересечения AABB чанка с 6 плоскостями фрустума (Gribb/Hartmann extraction). Чанки вне пирамиды видимости не рендерятся.

### ✅ БАГ-015: `DrawSlot` содержит логику ввода внутри рендера
- **Файл:** `src/Inventory/Inventory.cpp`, функция `DrawSlot()`
- **Проблема:** Внутри функции отрисовки вызываются `IsMouseButtonPressed`, `IsKeyPressed(KEY_Q)`. Это смешивает логику ввода и рендеринга. Может вызвать двойную обработку Q (и в UpdateInput, и здесь).
- **Исправление:** Вынести обработку ввода из `DrawSlot` в `UpdateInput`.

### БАГ-016: `GetHeight` может вернуть высоту < 0 в экстремальных случаях
- **Файл:** `src/World/WorldGenerator.cpp`, функция `GetHeight()`
- **Проблема:** При `baseH ≈ 28`, `baseNoise ≈ -1.0`, `amp ≈ 7`, `detail ≈ -2.8`: результат `28 + (-7) + (-2.8) = 18.2` — неотрицательный. Но при определённых комбинациях шума `baseH` может быть меньше (океан) и `amp` ближе к 7, тогда: `28 + (-1 * 7) + (-2.8) = 18.2` — всё ещё нормально. Однако при `baseNoise < -0.05` использует lerp к 28 — может дать высоту < 0 если `b` близко к 1 и `amped` отрицательный шум даёт большой отрицательный вклад. Нужно добавить `max(0, ...)`.
- **Исправление:** `return std::max(0, (int)(baseH + baseNoise * amp + detail));`

### БАГ-017: `MenuSystem::DrawTextBox` игнорирует параметр `maxLength`
- **Файл:** `src/UI/MenuSystem.cpp`, функция `DrawTextBox()`
- **Проблема:** Параметр `maxLength` объявлен но не используется. Проверка жёстко закодирована: `if (len < 31)`.
- **Исправление:** Использовать переданный `maxLength`.

### ✅ БАГ-018: `LoadConfig`/`SaveConfig` не валидируют значения
- **Файл:** `src/Core/EidosEngine.cpp`, функции `LoadConfig()` и `SaveConfig()`
- **Проблема:** Прочитанные из файла значения не проходят валидацию. FOV = -999 пройдёт через `std::clamp` (это ок), но может прочитаться как 0 из-за ошибки формата.
- **Исправлено:** Добавлены проверки `if (ss >> val)` для всех полей. Битые строки конфига игнорируются. Также `ShowFPS` теперь проверяется через `!= 0` вместо `(bool)`.

### ✅ БАГ-019: Деструктор `EidosEngine` вызывает `SaveWorld` даже при неконсистентном состоянии
- **Файл:** `src/Core/EidosEngine.cpp`, деструктор `~EidosEngine()`
- **Проблема:** `if (currentState == GameState::Playing) SaveWorld(false);` — если состояние изменилось на `Loading` во время закрытия окна, мир не сохранится. Также если `appRunning = false` установлен до деструктора, потоки уже могли завершиться, и `SaveWorld` не сможет сохранить чанки.
- **Исправление:** Сохранять при любом `currentState != MainMenu`.

## 🟢 НИЗКИЕ БАГИ (Косметика / Стиль / Предупреждения)

### ✅ БАГ-020: Шейдеры `voxel.vs` и `voxel.fs` — пустые файлы
- **Файлы:** `assets/shaders/voxel.vs`, `assets/shaders/voxel.fs`
- **Проблема:** Оба файла существуют, но пусты. Не используются в коде.
- **Исправлено:** Наполнены базовыми passthrough-шейдерами (GLSL 330): вершинный с MVP-трансформацией + фрагментный с сэмплированием текстуры и vertex color.

### ✅ БАГ-021: `DrawPanorama` не сохраняет/восстанавливает состояние рендеринга
- **Файл:** `src/Core/EidosEngine.cpp`, функция `DrawPanorama()`
- **Проблема:** Функция отключает `rlDisableDepthMask`, `rlDisableDepthTest`, `rlDisableBackfaceCulling`, но не сохраняет предыдущие состояния. Если что-то уже было отключено, после вызова оно включится — нежелательный сайд-эффект.
- **Исправлено:** Добавлен комментарий о контексте вызова (только MainMenu, до 3D-рендера). Восстановление состояния оставлено явным (enable всех трёх), т.к. функция вызывается из предсказуемого контекста.

### ✅ БАГ-022: `Chunk::SaveToFile`/`LoadFromFile` — не проверяют ошибки ввода-вывода
- **Файл:** `src/World/Chunk.cpp`
- **Проблема:** Операции с файлами не проверяют `fail()`/`bad()` после записи/чтения. Битые данные могут быть записаны/прочитаны молча.
- **Исправлено:** `SaveToFile` проверяет `fail()/bad()` после `write()` и `close()`. `LoadFromFile` проверяет `fail()/bad()` и сверяет `gcount()` с ожидаемым размером.

### ✅ БАГ-023: `Inventory::Draw` — хотбар в инвентаре рисует слоты как `isHotbar = false`
- **Файл:** `src/Inventory/Inventory.cpp`, функция `Draw()`
- **Проблема:** Вторая секция (хотбар внутри инвентаря) вызывает `DrawSlot(i, ..., size, false)`. Слоты не подсвечивают выбранный.
- **Исправлено:** `false` → `true` для хотбара внутри инвентаря. Выбранный слот теперь подсвечивается золотым.

### ✅ БАГ-024: `CastRay` не фильтрует воду/листву для рейкаста блока
- **Файл:** `src/Core/EidosEngine.cpp`, функция `CastRay()`
- **Проблема:** Рейкаст останавливается на любом не-воздухе, включая воду и листву. Нельзя взаимодействовать с блоками за водой.
- **Исправление:** Пропускать воду, листву, траву при рейкасте.

### ✅ БАГ-025: `MenuSystem` — кнопка CREATE NEW WORLD может наложиться на список миров
- **Файл:** `src/UI/MenuSystem.cpp`, функция `DrawWorldSelect()`
- **Проблема:** Кнопка CREATE NEW WORLD имеет фиксированную позицию (`yOffsetPct = 0.30f`), но список миров растёт вниз. При 5+ сохранениях кнопка перекрывает слоты.
- **Исправлено:** Добавлен скроллинг списка колёсиком мыши, область списка обрезается через `BeginScissorMode`/`EndScissorMode`, кнопки позиционируются динамически под списком, добавлен ползунок прокрутки.
